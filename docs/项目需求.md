# 番茄小说自动化平台 - 项目需求文档

## 一、项目概述

### 1.1 项目目标
构建单用户番茄小说自动化创作平台，实现**创意采集 → AI 辅助创作 → 人工审核 → 自动发布**的全流程自动化。

### 1.2 核心价值
- **提升效率**：AI 自动生成内容，减少 80% 的写作时间
- **多书并行**：同时维护 3-5 本小说，提高产出
- **质量保证**：人工审核机制，确保内容质量
- **自动化发布**：浏览器自动化，解放双手

### 1.3 核心约束
- 单用户使用，功能完整性优先
- 多书并行更新（3-5 本书同时维护）
- AI 生成内容，人工审核后发布
- LLM 服务可配置多 Provider（支持 OpenAI、通义千问等）

## 二、技术架构

### 2.1 技术栈

**前端**
- React 18 + TypeScript
- 构建工具：Vite
- 状态管理：Zustand
- UI 组件：Ant Design
- 数据可视化：ECharts

**后端**
- Django 4.2 + Django REST Framework
- FastAPI（AI 生成服务）
- Celery + Redis（异步任务）
- MySQL（数据存储）
- Playwright（浏览器自动化）

**部署**
- Docker + Docker Compose
- Nginx（反向代理）

│         Django REST API                  │

└─────┬───────────────────────┬───────────┘

┌─────────────┐      ┌──────────────────┐

## 四、数据模型

### 4.1 核心表结构

| 表名 | 说明 | 关键字段 |
|------|------|----------|
| User | 用户表 | username, email, password, is_staff |
| LLMProvider | LLM 服务配置 | user_id, name, provider_type, api_url, api_key, task_type, priority |
| Inspiration | 创意表 | source_url, title, synopsis, tags, hot_score, is_used |
| NovelDraft | 新书草稿表 | user_id, inspiration, title, genre, current_step, is_completed |
| DraftSetting | 草稿设定表 | draft_id, setting_type, title, content, structured_data |
| NovelProject | 小说项目表 | user_id, title, genre, synopsis, outline, status, current_chapter |
| NovelSetting | 小说设定表 | project_id, setting_type, title, content, structured_data |
| Chapter | 章节表 | project_id, chapter_number, title, raw_content, final_content, status |
| Task | 任务表 | task_type, related_type, related_id, status, celery_task_id |
| Stats | 统计表 | date, metric_type, metric_data |

### 4.2 状态流转

```
Inspiration: collected → used
NovelDraft: created → (12步) → completed → 转为 NovelProject
NovelProject: active ←→ paused → completed/abandoned
Chapter: generating → pending_review → approved → published
         ↓ (失败)
       failed → (可重新生成)
Task: pending → running → success/failed
```

## 五、API 接口设计

### 5.1 认证接口
- `POST /api/users/login/` - 登录
- `POST /api/users/refresh/` - 刷新 Token
- `GET /api/users/me/stats/` - 用户统计

### 5.2 创意管理接口
- `GET /api/inspirations/` - 创意列表
- `POST /api/inspirations/` - 创建创意
- `POST /api/inspirations/generate-from-trends/` - 从热门书生成
- `POST /api/inspirations/generate-custom/` - 自定义生成

### 5.3 草稿管理接口（新书向导）
- `POST /api/drafts/` - 创建草稿
- `GET /api/drafts/` - 草稿列表
- `GET /api/drafts/<id>/` - 草稿详情
- `PATCH /api/drafts/<id>/` - 更新草稿
- `POST /api/drafts/<id>/save-step/` - 保存某步设定
- `GET /api/drafts/<id>/settings/` - 获取所有设定
- `POST /api/drafts/<id>/complete/` - 完成向导，创建项目

### 5.4 项目管理接口
- `GET /api/novels/` - 项目列表
- `POST /api/novels/` - 创建项目
- `GET /api/novels/<id>/` - 项目详情
- `PATCH /api/novels/<id>/` - 更新项目
- `GET /api/novels/<id>/generation-status/` - 生成进度
- `POST /api/novels/<id>/start-auto-generation/` - 启动自动生成
- `POST /api/novels/<id>/stop-auto-generation/` - 停止自动生成
- `POST /api/novels/<id>/generate-next-chapter/` - 生成下一章

### 5.5 章节管理接口
- `GET /api/chapters/` - 章节列表
- `POST /api/chapters/` - 创建章节
- `GET /api/chapters/<id>/` - 章节详情
- `PATCH /api/chapters/<id>/` - 更新章节
- `POST /api/chapters/<id>/publish/` - 发布章节

### 5.6 AI 生成接口（FastAPI）
- `POST /api/ai/generate/book-titles` - 生成书名
- `POST /api/ai/generate/outline` - 生成大纲
- `POST /api/ai/generate/chapter` - 生成章节
- `POST /api/ai/continue` - 内容续写
- `POST /api/ai/generate/setting` - 生成设定
- `WebSocket /ws/generate-setting` - 流式生成设定
- `WebSocket /ws/chapter` - 流式生成章节

### 5.7 数据统计接口
- `GET /api/stats/overview/` - 首页概览
- `GET /api/stats/chapter-analytics/` - 章节分析
- `GET /api/stats/character-graph/` - 角色关系图
- `GET /api/stats/trend/` - 趋势数据

## 七、自动化流程

### 7.1 定时任务

```python
CELERYBEAT_SCHEDULE = {
    # 每天早上 8 点自动生成章节
    'auto-generate-chapters': {
        'task': 'celery_tasks.ai_tasks.auto_generate_chapters_daily',
        'schedule': crontab(hour=8, minute=0),
    },
}
```

### 7.2 完整工作流程

```
1. 创意生成
   ├─ AI 分析生成创意
   └─ 保存到创意库

2. 新书向导（12 步）
   ├─ 输入灵感创建草稿
   ├─ AI 生成书名（多选项）
   ├─ AI 生成世界观（8 维度）
   ├─ AI 生成人物设定
   ├─ AI 生成地图场景
   ├─ AI 生成故事线
   ├─ AI 生成情节弧
   ├─ AI 生成开篇场景
   └─ 确认创建正式项目

3. 自动生成章节
   ├─ 配置自动生成频率
   ├─ Celery Beat 定时触发
   ├─ 调用 FastAPI 生成内容
   └─ 保存章节（状态: pending_review）

4. 人工审核编辑
   ├─ 查看生成的章节
   ├─ Markdown 编辑器修改
   ├─ 保存修改
   └─ 标记为 approved

5. 自动发布
   ├─ 点击发布按钮
   ├─ Playwright 浏览器自动化
   ├─ 模拟登录番茄小说后台
   ├─ 自动填写表单发布
   └─ 更新状态为 published
```

## 八、风险控制

### 8.1 成本控制
- LLM 调用失败重试上限（3 次）
- Token 消耗监控与告警
- 按 Provider 优先级降级

### 8.2 合规约束
- 所有 AI 内容必须人工审核
- 发布前二次确认
- 操作日志完整记录

### 8.3 安全措施
- API Key 加密存储
- JWT Token 认证
- CORS 跨域保护
- SQL 注入防护
