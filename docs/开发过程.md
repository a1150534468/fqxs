def generate_chapter_async(self, project_id, chapter_number, chapter_title):

### 3.2 多 LLM Provider 支持

**实现思路**：
1. 统一接口抽象（`llm_provider_manager.py`）
2. 按任务类型和优先级选择 Provider
3. 失败自动降级到下一个 Provider

**关键代码**：
```python
# fastapi_service/services/llm_provider_manager.py
class LLMProviderManager:
    async def call_llm(self, system_message, user_message, providers):
        for provider in sorted(providers, key=lambda p: p['priority']):
            try:
                if provider['provider_type'] == 'openai':
                    return await self._call_openai(provider, system_message, user_message)
                elif provider['provider_type'] == 'qwen':
                    return await self._call_qwen(provider, system_message, user_message)
            except Exception as e:
                logger.warning(f"Provider {provider['name']} failed: {e}")
                continue
        
        raise Exception("All providers failed")
```

### 3.3 API Key 加密存储

**实现思路**：
1. 使用 cryptography 库的 Fernet 对称加密
2. 加密密钥存储在环境变量中
3. 数据库只存储加密后的密文

**关键代码**：
```python
# backend/apps/providers/models.py
from cryptography.fernet import Fernet
from django.conf import settings

class LLMProvider(models.Model):
    api_key_encrypted = models.TextField()
    
    def set_api_key(self, api_key):
        cipher = Fernet(settings.ENCRYPTION_KEY.encode())
        encrypted = cipher.encrypt(api_key.encode())
        self.api_key_encrypted = encrypted.decode()
    
    def get_api_key(self):
        cipher = Fernet(settings.ENCRYPTION_KEY.encode())
        decrypted = cipher.decrypt(self.api_key_encrypted.encode())
        return decrypted.decode()
```

## 六、常见问题

### 6.1 数据库连接失败
**问题**：`django.db.utils.OperationalError: (2003, "Can't connect to MySQL server")`

**解决**：
1. 检查 MySQL 是否启动：`docker compose ps`
2. 检查数据库配置：`.env` 文件中的 `DATABASE_URL`
3. 等待 MySQL 完全启动（约 30 秒）

### 6.2 Celery 任务不执行
**问题**：定时任务没有触发

**解决**：
1. 检查 Celery Beat 是否启动：`ps aux | grep celery`
2. 检查 Redis 连接：`redis-cli ping`
3. 查看 Celery 日志：`celery -A config worker -l debug`

### 6.3 前端无法连接后端
**问题**：`Network Error` 或 CORS 错误

**解决**：
1. 检查后端是否启动：`curl http://localhost:8000/api/`
2. 检查 CORS 配置：`backend/config/settings.py` 中的 `CORS_ALLOWED_ORIGINS`
3. 检查前端 API 地址：`frontend/.env` 中的 `VITE_API_BASE_URL`

### 6.4 WebSocket 连接失败
**问题**：WebSocket 无法建立连接

**解决**：
1. 检查 FastAPI 是否启动：`curl http://localhost:8001/`
2. 检查 WebSocket URL：应该是 `ws://` 而不是 `http://`
3. 检查防火墙设置

### 6.5 LLM API 调用失败
**问题**：`401 Unauthorized` 或 `429 Too Many Requests`

**解决**：
1. 检查 API Key 是否正确
2. 检查 API 额度是否用完
3. 检查网络连接（可能需要代理）
4. 降级到其他 Provider
